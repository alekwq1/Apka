# FUJARA 1.0.0 — release

Finalny release po testach.

- Szybsza aktualizacja ekranu Start po zapisaniu zlecenia.
- Tempo dnia i kwota pozostała do celu są widoczne na ekranie Start.
- Analiza pokazuje również łączną liczbę godzin dla dni, z uwzględnieniem czasu odczytanego i wprowadzonego ręcznie.
- Dla fujarnych restauracji i odbiorców wyświetlany jest czerwony `FUJARA Alert`.
- Dla zuchów z napiwkiem wyświetlany jest zielony `NAPIWEK ALERT`.
