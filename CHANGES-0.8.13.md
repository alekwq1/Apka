# FUJARA 0.8.13

UI refresh inspirowany prostymi aplikacjami finansowymi/bankowymi:

- przebudowany ekran Start: duży ciemny kafel ostatniego wyniku, PLN/h i PLN/km oraz szybkie metryki,
- spokojniejsza paleta: jasnoszare tło, białe karty, ciemne kafle wynikowe i kolory tylko tam, gdzie niosą znaczenie,
- nowy ciemny dolny pasek nawigacji z czytelnymi ikonami Start / Dzień / Analiza / Ustawienia,
- uproszczone karty i nagłówki w całej aplikacji (mniej ramek, większe promienie, więcej odstępu),
- ekran Analiza obsługuje zakresy 7 dni / 30 dni / 3 miesiące / rok,
- wykres wyniku po kosztach w Analizie tworzony z rzeczywiście zatwierdzonych dni,
- nowy główny kafel Analizy: wynik po kosztach, PLN/h, PLN/km, przychód i liczba zleceń,
- lista dni w Analizie w formie czytelnych kart finansowych,
- wynik dnia Pyszne jako duży ciemny dashboard z wynikiem po kosztach,
- wykres PLN/h kolejnych zleceń w podsumowaniu dnia,
- zachowana dotychczasowa logika liczenia, zapisu wyników, pojedynczych zleceń i szczegółów.

Wersja: 0.8.13 (versionCode 30).
